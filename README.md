# Nauticode

Welcome to Nauticode! An interactive learning platform for robotics and programming.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Seeding the Database

If you modify the curriculum in the `classes/` folder, update the database by running:

```bash
pnpm db:push
pnpm db:prod
```
